# Mert's Agent Rules

Reusable coding-agent rules by [Mert Creates](https://github.com/mertcreates).

## Purpose

`AGENTS.md` defines a compact operating contract for coding agents: how to decide, when to ask, how to verify, how to edit, and how to carry durable lessons forward.

## How To Use It

- Copy or reference `AGENTS.md` in a repo.

## Contents

- `AGENTS.md`: core agent rules
- `.gitignore`: local OS noise.
